# Boot dot Dev Asteroids project

I plan to use this to make a more fleshed out version, just for fun.

It is written in Python, and therefore you have to have it installed to use it.

The base work was from following a Boot dot Dev project.

It will be improved eventually, and it already has a few extras.

---

**Motivation behind the project:**  

I am a gamer, and have been for a long time. I have played countless games. Sometimes I think it would be more interesting if they could do other things. A good example would be being able to upgrade your ship with random choices, like in Vampire Survivors. I've never seen that in an Asteroids game.

---

## Quick Start Guide

You must have Python installed. This was made using Python v3.16.  
Clone the repo, and then simply run:
```bash
python3 main.py
```

---

## Usage of the application

A simple Asteroids clone. A and D turn, W moves forward, S moves backwards, SPACE fires.
